# Situation Monitor

Real-time environmental dashboard for 11 cities across the world.
Built as a single self-contained HTML file — no build step, no server required.

## How to open

Open `situation-monitor.html` in any modern browser (Safari, Chrome, Firefox).
Requires an internet connection for map tiles, weather data and fonts.

## Cities (west → east)

Honolulu · San Jose · Tahoe City · New York · London · Turku · Tampere · Helsinki · Istanbul · Dubai · Sydney

## Data sources (all free, no API key required)

- Weather, UV, pressure, wind: Open-Meteo
- Air quality (AQI, PM2.5, NO₂): Open-Meteo AQI
- Sunrise / sunset: Sunrise-Sunset.org
- Map tiles: CartoDB Voyager
